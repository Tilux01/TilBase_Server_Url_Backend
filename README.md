# TilBase URL Service

Small backend service that manages URLs for the TilBase ecosystem.

## About

A lightweight Node.js service that handles URL generation and routing for TilBase services.

## Features

- URL generation
- Service routing
- Simple and fast

## Tech Stack

- Node.js
- Express

## Getting Started

Clone the repository and open the project in your browser or run it with your preferred local server.
